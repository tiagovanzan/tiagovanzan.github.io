Política de privacidade

O Obsidian Calendar API acessa dados do Google Calendar apenas para exibi-los e sincronizá-los com notas no computador do próprio usuário.

  • Os dados ficam armazenados somente localmente; não são enviados a servidores de terceiros.
  • Os dados não são vendidos, compartilhados nem usados para publicidade.
  • O uso de dados recebidos das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de Uso Limitado.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
